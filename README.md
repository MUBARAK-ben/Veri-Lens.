Veri-Lens:Misinformation & Scam Spotter Lab is a modular front-end web application designed to build digital literacy and scam-detection skills through hands-on scenario analysis. Rather than simply telling users what is fake, the workspace lets learners examine individual message segments, toggle forensic inspection lenses, track pinned red flags, make verdict decisions, and earn points and streaks while learning practical defense habits. It also includes dynamic localization across English, Hausa, and Arabic
